# 安全边界

## 范围

Sentinel 是一个**本地运维健康看板**。它从运行服务的主机发起 ICMP、TCP、TLS 与 HTTP 探测，并把结果展示给同一台主机上的操作者。

它**不是**：

- 公网可暴露的监控平台；
- 完整的外部安全扫描器；
- 漏洞利用或资产测绘工具。

## 默认防护

| 项 | 默认行为 |
|---|---|
| 监听地址 | `127.0.0.1` |
| 认证 | 无内置账号体系，因此不应对公网开放 |
| 进程权限 | 以当前用户身份运行，不需要管理员权限 |
| URL 凭据 | 配置解析拒绝 HTTP URL 中的 userinfo |
| 命令执行 | 不使用 shell；`ping` 参数来自严格校验的主机名 / IP |
| 静态文件 | 路径解析限制在 `dashboard/` 内，拒绝目录穿越 |
| 响应头 | CSP、`nosniff`、`Referrer-Policy`、`X-Frame-Options: DENY` |
| 报告导出 | 移除 URL 中的用户信息、查询参数与片段 |
| 外部回传 | 不向任何第三方发送配置或结果 |

## 信任边界

- `checks.json` 由本机操作者维护。**不要把密码、Token、Cookie、私钥写入配置。**
- 检查名称、分组、错误描述也会进入页面与报告，同样不得存放秘密。
- 目标主机可能返回任意文本；前端与报告均进行 HTML 转义。
- 远程探测目标应属于你有权检测的资产范围。

## 已知限制

- 无内置认证：如需局域网访问，请在反向代理层增加身份认证与 TLS。
- 历史记录保存在本地 JSONL，未加密。逐项记录只写入 `id`、状态与延迟，但整轮摘要和事件仍可能暴露资产标识；请按本机文件权限保护。
- 单次配置最多 200 项检查，单轮逐项历史记录也按 200 项截断；历史内存窗口默认 240 轮，页面只请求最近 40 轮。
- 低频轮询无法替代持续采样或真实用户监控。
- TLS 检查只验证证书链、到期时间与握手结果，不评估协议配置全貌。
- ICMP 可能被目标或中间网络策略禁止，失败不等于主机下线。

## 报告安全问题

请通过仓库 Issue 或维护者提供的私密渠道报告，包含：

1. 受影响版本与提交；
2. 复现条件；
3. 实际观察到的证据；
4. 影响评估；
5. 建议修复方式。

不要在公开 Issue 中粘贴凭据、真实内网地址或完整生产配置。
